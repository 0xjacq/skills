# Interaction Rules

Use interactivity only when it improves understanding.

## Allowed

- tabs for alternate views
- collapsible dense sections
- show or hide annotations
- filters by module, layer, or tag
- glossary toggles
- copy buttons for commands or snippets
- clickable architecture maps
- reveal panels for metadata, sources, or commit context

## Avoid

- drag and drop
- freeform editing
- heavy local state
- complex forms
- simulation controls
- workflow apps
- anything that feels like a product UI rather than a comprehension artifact

## Rules

- Keep controls quiet and secondary.
- The page must remain understandable with all controls untouched.
- Interactive elements must degrade gracefully on mobile.
- Never hide critical content behind interaction.
- Default state should show the core story first.
