# Imagegen Usage

Use `imagegen` only when a raster visual materially improves comprehension.

## Good uses

- educational cover image
- mental-model illustration
- memorable visual anchor for onboarding
- section opener in a long explainer
- explanatory scene that complements a technical diagram

## Bad uses

- architecture topology
- sequence diagrams
- precise flow maps
- code annotation
- comparison matrices
- anything cleaner in SVG or HTML

## Rules

- Prefer one meaningful visual over many decorative ones.
- Keep generated images subordinate to the document's technical content.
- If a generated image is used, pair it with clear captioning.
- Do not let the image imply technical precision it does not have.
- Use SVG overlays when precise labels or callouts are needed.

## Prompt direction

Ask for:
- educational
- calm
- diagram-friendly composition
- clean negative space
- restrained palette
- no embedded text unless explicitly required
